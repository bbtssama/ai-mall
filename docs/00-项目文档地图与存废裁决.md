## 一、全景地图：这些文件分别是什么

整个项目文档分为**五层**，理解分层就理解了为什么会有这么多文件：

```
第 0 层  工作区指令（元层）  AGENTS.md
第 1 层  设计蓝图（最初的规划）项目设计文档.md
第 2 层  版本演进详解（教学向）V1.5 / V2 / V3 / V4 详解 + 词典（8 个文件）
第 3 层  AI 专题教程（教学向） AI模块详解 + 词典 + RAG零基础（3 个文件，8000+ 行）
第 4 层  求职材料（当前在用）  后端求职/（简历C + 超链目录 + 试卷 + 自评）
第 5 层  工程附属（工具产物）  docs/ + dsh-window/ + scripts/ + sql/ + 日志
```

**关键洞察**：第 2、3 层是**学习过程的产物**（AI 生成的教学材料），第 4 层才是**当前真正的产出**。用户现在只用第 4 层里的**简历 C**，其余基本处于"已完成历史使命"状态。
