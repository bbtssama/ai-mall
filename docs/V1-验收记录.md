## 五、关键技术落地备忘

### 1. 下单防超卖（乐观扣减）
```sql
UPDATE t_product_sku SET stock=stock-?, sales=sales+?
WHERE id=? AND stock>=?
```
返回 0 行 = 并发下库存不足 → 抛 `BusinessException(STOCK_NOT_ENOUGH)`；`@Transactional` 整体回滚。
V3 将升级为 Redis 预减 + Redisson 分布式锁三保险。

### 2. 统一返回体的一个坑（踩坑记录）
早期项目 `R.ok(String msg)` 与泛型 `R.ok(T data)` 重载并存，
当 `R.ok(chatService.chat(req))` 传 String 时 Java 解析到 `ok(String)`，导致 data=null（回答丢失）。
**本项目去掉单参 `ok(String)`，保留 `ok(T data)` / `ok(String msg, T data)`** —— 已同步设计文档修订记录。

### 3. 数据库连接字符集
JDBC URL 的 `characterEncoding` 必须用 `UTF-8`，写成 `utf8mb4` 会报
`Unsupported character encoding`。库/表/连接三项字符集对齐 utf8mb4/UTF-8。

### 4. 风格对齐（order-system-v2 / blog-system）
- 实体包 `entity` → `bean`；Controller → `XxxRestController`
- 接口前缀统一 `/api/v1`；Mapper 逐接口 `@Mapper`（去 `@MapperScan`）
- `PageResult{records,total,page,pageSize}` + `of(...)` 工厂
- 手写 `LIMIT/COUNT` 分页，不引 PageHelper/MyBatis-Plus
